# Argus Grid

A distributed visual inspection agent network. Instead of one vision-agent bot watching one camera feed, Argus Grid runs a local **Vision Agent** at every site (construction site PPE/safety compliance, to start), a central **Orchestrator** that reasons across sites for patterns a single-site bot can't see, and specialist **Triage** and **Reporting** agents it delegates to over real agent-to-agent tasks.

Full architecture, phased build plan, and setup instructions land here as the project comes together — see PRs for build history.
